# ₊⊹ ✴︎ Zentria CLI — v1.2.0 "Premium Evolution"

_Release Date: 06 abr 2026_

Versión mayor que consolida la transformación visual del CLI, introduciendo un sistema de renderizado "Flicker-Free", navegación por capas y un catálogo expandido de temas Pro.

---

## 🚀 Highlights

- **Estabilización de Pantalla Única**: El CLI ahora ocupa exactamente el tamaño de la terminal, eliminando el scroll y saltos de línea.
- **Renderizado Optimizado**: El nuevo motor `SelectedGradient` por "chunks" elimina el parpadeo en las transiciones de color.
- **Paginación Inteligente**: Selector de temas con ventana deslizante (máximo 6 ítems visibles), permitiendo navegación fluida en cualquier resolución.
- **Recuperación Activa (Ctrl+R)**: Nueva función global para forzar la limpieza y el redibujado de la terminal ante cualquier artefacto del sistema.
- **Fix de Autenticación Crítico**: Soporte multi-mapeo para tokens de backend (`access_token`, `token`, `data.token`).

## 🎨 Temas Pro [Nuevos]

Se han añadido 5 temas visuales optimizados para máxima legibilidad y estética:
- **Cyberpunk ⚡**: Neones amarillos y magentas vibrantes.
- **Matrix 📟**: Estética hacker clásica en verdes eléctricos.
- **Retro 🕹**: Inspirado en el estilo Synthwave/Vaporwave.
- **Dracula 🧛🏻‍♂️**: El esquema de color definitivo ajustado para TUI.
- **Nórdico 🏔**: Colores fríos y elegantes para largas jornadas.

## 🛠 Cambios Técnicos

- **Navegación**: Introducción de `SettingsMenuView` y `SystemInfoView` para separar la info técnica de la configuración de apariencia.
- **Refactor de Shell**: El componente `app.tsx` ahora gestiona la geometría de la terminal de forma estricta (`height={rows - 1}`).
- **Resolución de Rutas**: Fix en el despacho de tickets offline para localizar plantillas dinámicamente dentro de la arquitectura SEA.
- **Keys Estables**: Implementación de `key` únicas para todos los bloques de React, evitando "ghosting" de texto.

## 📦 Distribución

- **Binario**: `zentria-cli-v1.2.0.exe` (~85MB).
- **Entorno**: Compatible con Windows CMD, PowerShell y Windows Terminal.
