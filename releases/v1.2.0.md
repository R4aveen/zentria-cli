## Resumen

La versión **v1.2.0** marca un punto de inflexión en la madurez técnica del **Zentria CLI**. Tras resolver los bloqueos de seguridad en la v1.1.6, esta actualización se centra en eliminar la fricción técnica del usuario final: **inestabilidad visual (flickering)** y **errores de navegación**. Mediante un refactor completo del motor de renderizado y el control estricto de la geometría de la terminal, el CLI ahora ofrece una experiencia de "aplicación nativa" en entornos de consola limitados.

---

## Cambios Técnicos Destacados

### ✦ 1. Motor de Renderizado "Flicker-Free"
> **Problema:** En el CMD original de Windows, actualizar colores carácter por carácter provocaba un parpadeo constante que cansaba la vista.

**Solución Implementada en `SelectedGradient.tsx`:**  
Se ha rediseñado la lógica de renderizado para utilizar **agrupación por chunks**. En lugar de enviar un comando de color por cada letra, el motor ahora pre-calcula los bloques de texto que comparten el mismo color de degradado y los envía a la `stdout` en una sola operación.

```tsx
// Lógica de Chunking (Simplificada)
const chunks = useMemo(() => {
  // ... agrupa caracteres contiguos con el mismo colorIdx
  if (lastChunk.color === nextColor) {
    lastChunk.text += nextChar;
  } else {
    result.push({ text: nextChar, color: nextColor });
  }
}, [text, theme]);
```
**Resultado:** Reducción del ~70% en las llamadas de escritura, logrando transiciones de color instantáneas.

---

### ✦ 2. Arquitectura de Pantalla Única (Single-Screen)
**Archivo:** `source/app.tsx` / `useTerminalSize.ts`

El CLI ya no se comporta como una salida de texto continua (scroll), sino como un **buffer estático**.
*   **Pinning de Altura:** El contenedor principal (`Shell`) ahora calcula dinámicamente `rows - 1` y fija su altura. Esto evita que el prompt del sistema "empuje" la interfaz hacia arriba.
*   **Recuperación Activa (Ctrl+R):** Se ha implementado un "Hard Reset" visual global. Al presionar `Ctrl+R`, se limpia el buffer de la terminal y se fuerza un re-render completo de React, solucionando cualquier artefacto visual provocado por redimensionamientos externos.

---

### ✦ 3. Navegación Jerárquica y Paginación Inteligente
**Archivos:** `ThemeSelector.tsx`, `SettingsMenuView.tsx`, `SystemInfoView.tsx`

Se ha introducido un sistema de menús multinivel gestionado por un stack de vistas:
1.  **Sliding Window (Paginación):** El selector de temas ahora utiliza una ventana deslizante que muestra solo 6 de los 13 temas disponibles, rotando conforme el usuario navega. Esto garantiza que la lista nunca exceda el tamaño de la pantalla.
2.  **Gestión de ESC Mejorada:** Implementación de navegación por capas. La tecla `ESC` retrocede un paso en la jerarquía (ej: Selector -> Ajustes -> Menú) en lugar de simplemente cerrar la aplicación.

---

### ✦ 4. Resiliencia en Autenticación
**Archivo:** `source/components/LoginView.tsx`

Para evitar fallos de conexión tras actualizaciones del ERP, el servicio de login ahora es agnóstico a la estructura del payload de respuesta:
*   Mapea automáticamente si el token viene como `access_token`, `token` o dentro de un objeto `data`.
*   Añadido soporte para detección de tokens persistidos en variables de entorno para agilizar el desarrollo interno.

## Instrucciones de Despliegue

### Pipeline de Compilación
```bash
# 1. Generar bundle ESM
npm run bundle

# 2. Ejecutar generador SEA (Single Executable)
# Esto aplica iconos, inyecta el blob y firma digitalmente
node scripts/build-exe.mjs
```

### Verificación de Estabilidad
> [!TIP]
> Tras iniciar el ejecutable, redimensiona la ventana de terminal rápidamente. La interfaz debe adaptarse o, en su defecto, restaurarse presionando `Ctrl+R`. Si los bordes se duplican, verifica que no existan anidamientos de `flexGrow` sin ancho fijo en el componente afectado.
