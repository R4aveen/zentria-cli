# Zentria CLI - Release v1.2.1

> Fecha: 08 de abril de 2026
> Version: v1.2.1
> Estado: Estable

---

## Resumen

La version v1.2.1 es un patch release enfocado en estabilidad de construccion y publicacion.
No agrega features de interfaz nuevas sobre v1.2.0; corrige el flujo de empaquetado y release para que los usuarios finales descarguen siempre el ZIP compilado correcto.

---

## Cambios principales

### 1) Pipeline de Release robusto
- Se valida que el tag y la version de package.json coincidan.
- Se verifica que el archivo esperado build/Zentria-CLI-vX.Y.Z.zip exista antes de subirlo.
- Si falta el ZIP o hay mismatch de version, el workflow falla con mensaje explicito.

Archivo clave:
- .github/workflows/release.yml

### 2) Build local ordenado con archivado automatico
- Los ZIP de versiones anteriores se mueven automaticamente a build/archive/releases/vX.Y.Z/.
- Los artefactos legacy se mueven a build/archive/legacy/.
- La raiz de build queda con la version vigente.

Archivo clave:
- scripts/build-exe.mjs

### 3) Correccion de certificado y firma en Windows
- Se fuerza el uso de Windows PowerShell para scripts de certificado/firma.
- Se agregan validaciones para evitar falsos positivos en exportacion de .cer.
- Se mantiene firma del ejecutable con estado valido cuando el entorno lo permite.

Archivo clave:
- scripts/build-exe.mjs

## Instrucciones de publicacion (tag release)

1. Asegurar version en package.json: 1.2.1
2. Commit y push a main
3. Crear tag v1.2.1 y push del tag
4. Verificar Actions Build & Release
5. Confirmar asset en GitHub Release
